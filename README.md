# 🏦 Central de Suporte Bancário

Aplicação web para consulta de contatos bancários, solicitações de reembolso, contestações via MED PIX e geração de notificações formais.

---

## 🚀 Funcionalidades

- **Catálogo de Bancos:** Contatos diretos (SAC, Ouvidoria, WhatsApp) e códigos COMPE/BACEN das 22 principais instituições do Brasil.
- **Abertura de Chamados:** Gerador de protocolos com contagem regressiva de 80 dias para o Mecanismo Especial de Devolução (MED PIX).
- **Calculadora CDC (Art. 42):** Cálculo automático de restituição em dobro para cobranças indevidas.
- **Notificação Extrajudicial:** Gerador de documento jurídico fundamentado no CDC e resoluções do Banco Central.
- **Design High-Contrast:** Interface responsiva com fundo claro e cards escuros para alta visibilidade.

---

## 🛠️ Tecnologias

- **Frontend:** HTML5, CSS3 (Tailwind CSS), JavaScript (Vanilla ES6+)
- **Ícones & Estilo:** Lucide Icons, Plus Jakarta Sans
- **Persistência:** LocalStorage (navegador)
